# Artist Website

A minimal static artist portfolio website for GitHub Pages.

## Pages

- `index.html` - homepage
- `biography.html` - biography page
- `portfolio.html` - artwork grid
- `exhibitions.html` - exhibitions page
- `artworks/*.html` - individual artwork pages

## Replace placeholders

1. Replace `Artist Name` across the HTML files.
2. Replace `studio@example.com` with your real contact email.
3. Replace SVG placeholder images in `assets/images/full` and `assets/images/thumbnails` with optimized artwork images.
4. Update artwork titles, years, mediums, dimensions, and descriptions.

## GitHub Pages

Upload these files to your GitHub Pages repository, then enable GitHub Pages from the repository settings.
